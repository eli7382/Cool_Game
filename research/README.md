# Research source register

Research was collected for the game systems and production decisions in this run: audio and narration, rendering/materials, vehicle and flight behavior, environmental response, AI/combat, accessibility, QA, and the F-16A Netz pre-production brief.

## Count and access

- **552 distinct canonical source pages** are listed in `sources.csv`, exceeding the requested minimum of 512.
- **450 pages returned direct page text excerpts** through the web reader.
- **103 entries have search-result excerpts only** because direct text was unavailable or the page did not return within the bounded reads.
- The register contains 553 unique source IDs and exact URLs; common tracking/display parameters reduce these to 552 canonical pages. Direct reads were excerpts, not full-document reviews. The register records access level per row and does not claim that 552 complete documents were read cover to cover.

## Deduplication

The register removes URL fragments and common tracking, language, translation, and display parameters. It keeps content-identifying parameters such as Wwise page IDs. Identical canonical URLs are counted once.

## Sources

The search set emphasizes original vendor documentation, standards bodies, government flight/environment references, and primary research indexed by ACM, IEEE, SAE, AAAI, and NASA. Search-result relevance is not equal across all entries; use the direct URL and access level in the CSV when reviewing a specific claim.

These references informed implementation and pre-production choices. They are not bundled game assets or runtime dependencies. No third-party audio middleware was added to the pinned build.
